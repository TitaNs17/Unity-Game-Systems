# Restaurant Systems

`Legacy/` contains the original project-specific restaurant scripts in one place.

The newer reusable systems are organized by responsibility:

- `Core/` — menu and order flow
- `Customers/` — patience and customer-facing runtime logic
- `Kitchen/` — preparation stations
- `Management/` — economy and reputation
- `Tests/` — unit tests for the reusable layer
- `V2/` — seating, staff, stock, waste and shift systems
